# TTS-провайдеры

BookVoice поддерживает шесть провайдеров синтеза речи — три локальных и три облачных. Локальные запускают Python-сервер на вашем Mac и не отправляют текст в интернет. Облачные используют API сторонних сервисов.

## Обзор

| Провайдер | Тип | Частота | Формат | Скорость | Качество |
|-----------|-----|---------|--------|----------|----------|
| Silero | Локальный | 48 кГц | WAV | ★★★★★ | ★★★☆☆ |
| Kokoro | Локальный | 24 кГц | WAV | ★★★★☆ | ★★★★☆ |
| Qwen3 Local | Локальный | 24 кГц | WAV | ★★☆☆☆ | ★★★★★ |
| Qwen3 Cloud | Облачный | — | — | ★★★★☆ | ★★★★★ |
| ElevenLabs | Облачный | — | MP3 | ★★★★☆ | ★★★★★ |
| Custom API | Любой | — | WAV | — | — |

## Silero TTS

**Тип:** локальный
**Движок:** `SileroEngine` (PyTorch, torch.hub)
**Частота:** 48 кГц, 16-бит, моно

### Модели

| Модель | Язык | Голоса |
|--------|------|--------|
| `v4_ru` | Русский | aidar, baya, kseniya, xenia, eugene, random |
| `v3_en` | Английский | en_0 … en_117, random |
| `v3_de` | Немецкий | de_0 … de_4, random |
| `v3_fr` | Французский | fr_0 … fr_4, random |

### Параметры

| Параметр | Диапазон | По умолчанию | Описание |
|----------|----------|--------------|----------|
| Speaker | список | auto | Голос из набора модели |
| Speed | 0.5–2.0 | 1.0 | Скорость речи |

### Особенности

- Самый быстрый провайдер — синтез предложения занимает менее секунды
- Модели скачиваются автоматически при первом использовании (~50–100 МБ каждая)
- Русская модель `v4_ru` наиболее качественная в линейке

### Зависимости

```
torch>=2.0.0
torchaudio>=2.0.0
omegaconf
```

## Qwen3 TTS (локально)

**Тип:** локальный
**Движок:** `QwenTTSEngine` (Qwen3TTSModel из HuggingFace)
**Частота:** 24 кГц
**Устройство:** только CPU (MPS/Metal несовместим с PyTorch для данной модели)

### Модели

Пять моделей, разделённых на три типа — каждый со своим методом генерации:

#### Base (клонирование голоса)

| Модель | HuggingFace ID | Размер |
|--------|---------------|--------|
| `0.6B-Base` | `Qwen/Qwen3-TTS-12Hz-0.6B-Base` | ~1.2 ГБ |
| `1.7B-Base` | `Qwen/Qwen3-TTS-12Hz-1.7B-Base` | ~3.4 ГБ |

Копируют голос с образца аудио. Требуют загрузки референсного WAV-файла и (опционально) его транскрипта.

**Параметры:**

| Параметр | Диапазон | По умолчанию | Описание |
|----------|----------|--------------|----------|
| Language | строка | russian | Язык синтеза |
| Temperature | 0.6–1.5 | 0.9 | Случайность генерации |
| Top-K | 20–100 | 50 | Ширина выбора токенов |
| Top-P | 0.5–1.0 | 1.0 | Nucleus sampling |
| Repetition Penalty | 1.0–2.0 | 1.05 | Штраф за повторы |
| Do Sample | вкл/выкл | вкл | Сэмплирование vs. жадный поиск |
| Max New Tokens | 100–2048 | 2048 | Максимальная длина |
| Reference Audio | файл | — | **Обязателен.** WAV-файл с образцом голоса |
| Reference Text | строка | — | Транскрипт образца (повышает качество) |
| X-Vector Only | вкл/выкл | выкл | Быстрое клонирование (ниже качество) |
| Subtalker Temperature | 0.6–1.5 | по умолч. модели | Параметры эмбеддинга голоса |
| Subtalker Top-K | 20–100 | по умолч. модели | |
| Subtalker Top-P | 0.5–1.0 | по умолч. модели | |
| Subtalker Do Sample | вкл/выкл | вкл | |

**Кэширование:** эмбеддинг голоса (voice clone prompt) извлекается из образца один раз и переиспользуется для всех сегментов.

#### CustomVoice (встроенные голоса + инструкции)

| Модель | HuggingFace ID | Размер |
|--------|---------------|--------|
| `0.6B-CustomVoice` | `Qwen/Qwen3-TTS-12Hz-0.6B-CustomVoice` | ~1.2 ГБ |
| `1.7B-CustomVoice` | `Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice` | ~3.4 ГБ |

Девять предустановленных голосов. Поддерживают текстовые инструкции по эмоциям и стилю.

**Голоса:** aiden, dylan, eric, ono_anna, ryan, serena, sohee, uncle_fu, vivian

**Параметры:** те же, что у Base, кроме Reference Audio и Subtalker (не нужны). Плюс:

| Параметр | Описание |
|----------|----------|
| Speaker | Один из 9 голосов |
| Emotion / Instruct | Текстовая инструкция: «говори грустно», «шёпотом», и т.д. |

#### VoiceDesign (генерация голоса по описанию)

| Модель | HuggingFace ID | Размер |
|--------|---------------|--------|
| `1.7B-VoiceDesign` | `Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign` | ~3.4 ГБ |

Создаёт уникальный голос по текстовому описанию. Не требует ни образца, ни выбора из списка.

**Параметры:** те же генеративные (Temperature, Top-K, и т.д.). Плюс:

| Параметр | Описание |
|----------|----------|
| Voice Description | Описание голоса: «тёплый женский голос, средний тембр, спокойная интонация» |

### Производительность на CPU

На Apple Silicon (M2 Max, 96 ГБ) синтез одного предложения занимает **15–60 секунд** в зависимости от длины и модели. Это значительно медленнее Silero, но качество существенно выше.

Для длинных текстов стоит учитывать:
- Рассказ на 5000 слов → ~30–60 минут
- Роман → несколько часов

### Зависимости

```
qwen-tts
torch
torchaudio
soundfile
numpy
```

**Дополнительно:** SoX (`brew install sox`) — используется библиотекой для обработки аудио.

## Qwen3 TTS (облачно — DashScope)

**Тип:** облачный
**API:** DashScope (Alibaba Cloud)
**Модель:** `qwen3-tts-flash`

### Настройка

1. Зарегистрируйтесь на [DashScope](https://dashscope.aliyuncs.com/)
2. Получите API-ключ
3. Введите ключ в настройках BookVoice

### Параметры

| Параметр | Описание |
|----------|----------|
| Emotion / Instruct | Текстовая инструкция для стиля речи |
| Language | Язык синтеза |

### Особенности

- Не требует локального Python — работает через HTTP API
- Быстрее локальных моделей Qwen
- Текст отправляется на серверы Alibaba Cloud

## ElevenLabs

**Тип:** облачный
**API:** ElevenLabs REST API

### Настройка

1. Зарегистрируйтесь на [elevenlabs.io](https://elevenlabs.io)
2. Получите API-ключ
3. Введите ключ в настройках BookVoice

### Параметры

| Параметр | Диапазон | По умолчанию | Описание |
|----------|----------|--------------|----------|
| Voice ID | строка | — | Идентификатор голоса |
| Stability | 0.0–1.0 | 0.5 | Стабильность речи |
| Similarity Boost | 0.0–1.0 | 0.75 | Точность воспроизведения голоса |

### Особенности

- Профессиональное качество голосов
- Ответ в формате MP3 (конвертируется в WAV для обработки)
- Тарификация по количеству символов

## Custom API

**Тип:** любой (локальный или облачный)
**Протокол:** HTTP POST, JSON тело, WAV-ответ

### Настройка

Укажите URL и порт вашего TTS-сервера. BookVoice отправит стандартный JSON-запрос:

```json
{
  "text": "Текст для синтеза",
  "model": "имя-модели",
  "speaker": "голос",
  "speed": 1.0,
  "language": "russian"
}
```

Ожидаемый ответ: бинарные данные WAV с `Content-Type: audio/wav`.

### Совместимые серверы

Любой HTTP-сервер, принимающий POST с JSON и возвращающий WAV. Можно использовать:
- Свой FastAPI/Flask сервер
- Обёртку над XTTS, Bark, Piper и другими TTS-движками
- Прокси к облачным API

## Сравнение провайдеров по сценариям

| Сценарий | Рекомендация |
|----------|-------------|
| Быстрая озвучка короткого текста на русском | Silero v4_ru |
| Качественная озвучка с конкретным тембром | Qwen3 Base + образец голоса |
| Озвучка без образца голоса, с описанием | Qwen3 VoiceDesign |
| Профессиональное качество, англоязычный текст | ElevenLabs |
| Максимальная конфиденциальность | Любой локальный (Silero, Kokoro, Qwen3 Local) |
| Длинный текст, время не критично | Qwen3 Local (лучшее качество) |
| Длинный текст, нужна скорость | Silero или Qwen3 Cloud |
